# Finite Element Method playlists: exercises and code

Free online exercises for the eight Finite Element Method playlists on the YouTube channel It is Soft Info: https://www.youtube.com/@ItisSoftInfo

Start here: https://itissoftinfo.github.io/fem-course/

There is nothing to install or download. Change the yellow boxes and the results follow. All units are SI. Python code, for the videos that use it, is in this repository.
